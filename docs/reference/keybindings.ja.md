# TUIキー操作

[目次](README.ja.md) | [English](keybindings.md) | [詳細TUIガイド](../tui.ja.md)

| Key | 操作 |
|---|---|
| Ctrl+S / Ctrl+Q | 保存 / 終了 |
| Ctrl+R / Ctrl+E | Assemble / ResetしてRun |
| Ctrl+T / Ctrl+Space / Escape | Step / Continue / Pause |
| Ctrl+B / Ctrl+P | Breakpoint / Command Palette |
| Ctrl+G | Game Input Mode開始/終了 |
| Ctrl+1…5 | Source / CPU / Memory / Bus / Display |
| Ctrl+Z / Ctrl+Y / Ctrl+F | Undo / Redo / Search |
| Ctrl+] / Alt+Left / Alt+Right | 定義 / 履歴を戻る / 進む |

TabはSource内でIndent、他PaneでFocus移動です。Busは`[`/`]`、End、Enter、`+`/`-`、`f`、`<`/`>`、Memoryは`g`と16進4桁、DisplayはArrowを使います。Game Input ModeではArrow/WASDが方向、J/KがA/B、SpaceがStart、大文字がRelease、Escapeが全Release＋終了です。
