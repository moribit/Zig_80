# TUI Key Bindings

[Index](README.md) | [日本語](keybindings.ja.md) | [Detailed TUI guide](../tui.md)

| Key | Action |
|---|---|
| Ctrl+S / Ctrl+Q | save / quit |
| Ctrl+R / Ctrl+E | assemble / reset and run |
| Ctrl+T / Ctrl+Space / Escape | Step / Continue / Pause |
| Ctrl+B / Ctrl+P | breakpoint / Command Palette |
| Ctrl+G | enter/leave Game Input mode |
| Ctrl+1…5 | Source / CPU / Memory / Bus / Display |
| Ctrl+Z / Ctrl+Y / Ctrl+F | Undo / Redo / Search |
| Ctrl+] / Alt+Left / Alt+Right | definition / history back / forward |

Tab indents in Source and changes focus elsewhere. Bus uses `[`/`]`, End, Enter, `+`/`-`, `f`, and `<`/`>`. Memory uses `g` and four hexadecimal digits. Display uses arrows. In Game Input mode, arrows/WASD are directions, J/K are A/B, Space is Start, uppercase letters release, and Escape releases all and leaves.
